# Admin 渠道管理接入中心设计

## 目标

把 OceanDesk Admin 的“渠道管理”从占位页改为可操作的渠道接入中心。第一版复用现有平台 API，支持查看渠道能力、配置微信服务号回调凭据、轮换或停用凭据，以及查看和撤销渠道身份。Web 渠道展示本地端到端验证状态；微信客服与企业微信机器人保留清晰的待接入状态。

## 页面结构

页面由三块组成：渠道目录、渠道实例、渠道身份。渠道目录展示 Web、微信服务号、微信客服和企业微信机器人的当前能力与验证边界。渠道实例仅展示服务端返回的脱敏凭据元数据，并提供新增、轮换、停用、复制回调地址和联调说明。渠道身份将服务端身份记录与企业、用户目录关联展示，管理员只能撤销有效身份。

微信服务号配置表单要求先选择已有的有效企业应用绑定，再填写唯一渠道实例 ID 和回调 Token。绑定列表响应补充 `connectionId`，避免让管理员手工输入内部 UUID。Token 只在提交时进入请求，保存后不会从服务端取回或再次展示。

## 状态与安全边界

“已配置”仅表示加密凭据存在且启用，不表示微信真实在线。当前服务号只支持明文 XML 回调；AES/EncodingAESKey、真实客服消息发送、多实例重放存储和真实账号端到端联调仍未完成。页面必须明确显示这些限制，不能用本地测试结果冒充第三方联调。

所有管理操作继续由 `platform.manage` 服务端权限保护。凭据响应只使用固定掩码和元数据；身份撤销和凭据操作沿用服务端审计。页面提供加载、空、错误、提交中和移动端布局状态。

## 验收

- 类型检查和生产构建通过。
- Admin 可加载真实绑定、凭据和身份数据。
- 有有效绑定时可创建微信服务号凭据，并可轮换、停用。
- 回调地址可复制，页面明确标注明文模式和真实联调限制。
- 桌面与 390px 移动视口无横向溢出，主要操作可触达。
