# 快速开始

> **已弃用为内部组件（2026-09）**：`adp-chat-component` 现在只服务平台管理端调试页 `/admin/adp-chat`，不再对外分发或嵌入。UMD `<script>`、`window` 全局挂载、`mount()` 动态挂载等集成方式已移除。组件的实际用法以 `client/packages/app/src/pages/AdminAdpChat.vue` 为准。

`adp-chat-component` 只在本仓库 monorepo 内通过 workspace 依赖被 `client/packages/app` 引用，无需安装、发布或复制到外部项目。

## 引入

`client/packages/app` 的 `package.json` 已声明 workspace 依赖：

```json
{
  "dependencies": {
    "adp-chat-component": "workspace:*"
  }
}
```

组件库需要先构建出产物（`dist/es/`）才能被 app 引用：

```bash
cd client/packages/adp-chat-component
npm run build
```

## 基础使用

在页面中引入 `ADPChat` 与其样式，并传入 `api-config`。`ADPChat` 会通过它自动加载应用列表、会话列表、会话详情与用户信息：

```vue
<template>
  <ADPChat :api-config="apiConfig" />
</template>

<script setup lang="ts">
import { ADPChat, type ApiConfig } from 'adp-chat-component'
import 'adp-chat-component/dist/es/adp-chat-component.css'

const apiConfig: ApiConfig = {
  baseURL: '/api',
  // apiDetailConfig 可覆盖各接口路径，缺省使用 defaultApiDetailConfig
}
</script>
```

调试页还用 service 层的拦截器注入平台登录态失效处理：

```ts
import { setResponseInterceptor } from 'adp-chat-component'

setResponseInterceptor(undefined, (error) => {
  // 例如：捕获 401 并跳转登录
  return Promise.reject(error)
})
```

字段与事件的完整说明见 [ADPChat 组件](/docs/zh/components/chat-layout)。
