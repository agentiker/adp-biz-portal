# ADP Chat Component

> **已弃用为内部组件（2026-09）**：`adp-chat-component` 不再是对外可嵌入的 SDK。它现在只服务平台管理端的 ADP 调试页 `/admin/adp-chat`（`client/packages/app/src/pages/AdminAdpChat.vue`），导出面收敛为一个布局组件 `ADPChat`、axios 拦截器配置和少量类型。UMD/全局挂载入口、动态挂载 `mount()`、以及 ADP 管理面能力（定时任务/渠道/连接器/插件/技能/知识库）均已移除。

`adp-chat-component` 基于 Vue 3 + TDesign，封装了平台管理端 ADP 调试页所需的聊天界面。它随 monorepo 一起维护，仅由 `client/packages/app` 通过 workspace 依赖引用，不再对外发布或嵌入第三方站点。

## 包入口导出

包入口 `adp-chat-component` 只导出以下内容：

- `ADPChat` — 唯一的布局组件，承载应用/会话/消息的完整聊天界面。
- `configureAxios`、`setRequestInterceptor`、`setResponseInterceptor`、`httpService`、`defaultApiDetailConfig` — service 层的 axios 配置与拦截器（调试页用它注入平台登录态失效处理）。
- 类型：`ApiConfig`、`ApiDetailConfig`、`Application`、`AppPattern`、`ChatConversation`、`Record`、`Reference`、`QuoteInfo`、`ChatConfig`、`ChatMode`、`ThemeType`，以及枚举 `ScoreValue`。

`ADPChat` 通过 `api-config` 自动加载应用列表、会话列表、会话详情与用户信息，无需手动传入 `applications`/`conversations`/`chatList` 等数据。

## 快速开始

```vue
<template>
  <ADPChat :api-config="apiConfig" />
</template>

<script setup lang="ts">
import { ADPChat, type ApiConfig } from 'adp-chat-component'
import 'adp-chat-component/dist/es/adp-chat-component.css'

const apiConfig: ApiConfig = { baseURL: '/api' }
</script>
```

更完整的用法见 [快速开始](/docs/zh/components/quick-start) 与 [ADPChat 组件](/docs/zh/components/chat-layout)。
