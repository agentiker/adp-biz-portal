# ChatSender

消息输入和发送组件，基于原生 `textarea`。支持 Enter 发送、Shift+Enter 换行、Ctrl/⌘+Enter 插入换行，并在中文输入法组合态下不误发送；流式生成中显示停止按钮。

## vue中使用

```vue
<template>
  <ChatSender
    :is-stream-load="isLoading"
    @send="handleSend"
    @stop="handleStop"
  />
</template>
```
