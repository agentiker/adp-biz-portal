# 基础组件

> **内部参考**：`adp-chat-component` 已收敛为仅服务平台管理端调试页 `/admin/adp-chat` 的内部组件，包入口只导出 `ADPChat`。下列组件是 `ADPChat` 的内部构建块，本章节作为内部实现参考，它们不再作为可单独 `import` 的公开 SDK 组件对外提供。

本章节按分类列出 `ADPChat` 内部使用的 UI 组件，便于调试页维护时查阅其 Props/Events/Slots/Methods。

## 组件分类

### 布局组件
用于构建聊天界面结构的基础布局组件。
- **MainLayout** - 主内容区域布局

### 聊天组件
核心聊天功能组件。
- **Chat** - 主聊天消息列表容器
- **ChatItem** - 单条聊天消息项
- **Sender** - 消息输入和发送组件
- **AppType** - 应用类型选择器
- **BackToBottom** - 回到底部按钮

### 基础组件
支持常见功能的 UI 组件。
- **CustomizedIcon** - 自定义图标组件
- **AIWarning** - AI 免责声明警告

### 通用组件
用于各种用途的工具组件。
- **OptionCard** - 选项选择卡片
- **MdContent** - Markdown 内容渲染

## 使用示例

包入口只导出 `ADPChat`；调试页通过它承载全部聊天能力，上述内部组件由 `ADPChat` 组合，无需单独引入。

```vue
<template>
  <ADPChat :api-config="apiConfig" />
</template>

<script setup lang="ts">
import { ADPChat, type ApiConfig } from 'adp-chat-component'
import 'adp-chat-component/dist/es/adp-chat-component.css'

const apiConfig: ApiConfig = { baseURL: '/api' }
</script>
```
