# ADP Chat Component

> **Deprecated as an internal component (2026-09)**: `adp-chat-component` is no longer an embeddable SDK. It now serves only the platform admin ADP debugging page `/admin/adp-chat` (`client/packages/app/src/pages/AdminAdpChat.vue`), and its public surface is narrowed to a single layout component `ADPChat`, the axios interceptor config, and a few types. The UMD/global-mount entry, the dynamic `mount()` API, and the ADP management-plane capabilities (timer tasks / channels / connectors / plugins / skills / knowledge) have all been removed.

`adp-chat-component` is built with Vue 3 + TDesign and packages the chat interface needed by the platform admin ADP debug page. It is maintained inside this monorepo and consumed only by `client/packages/app` via a workspace dependency; it is no longer published or embedded into third-party sites.

## Package Exports

The `adp-chat-component` entry exports only:

- `ADPChat` — the single layout component that renders the full chat interface over applications / conversations / messages.
- `configureAxios`, `setRequestInterceptor`, `setResponseInterceptor`, `httpService`, `defaultApiDetailConfig` — the service-layer axios config and interceptors (the debug page uses them to handle platform session expiry).
- Types: `ApiConfig`, `ApiDetailConfig`, `Application`, `AppPattern`, `ChatConversation`, `Record`, `Reference`, `QuoteInfo`, `ChatConfig`, `ChatMode`, `ThemeType`, plus the `ScoreValue` enum.

`ADPChat` loads applications, conversations, conversation detail, and user info automatically through `api-config`; there is no need to pass in `applications` / `conversations` / `chatList` data manually.

## Quick Start

```vue
<template>
  <ADPChat :api-config="apiConfig" />
</template>

<script setup lang="ts">
import { ADPChat, type ApiConfig } from 'adp-chat-component'
import 'adp-chat-component/dist/es/adp-chat-component.css'

const apiConfig: ApiConfig = { baseURL: '/api' }
</script>
```

See [Quick Start](/docs/en/components/quick-start) and [ADPChat Component](/docs/en/components/chat-layout) for fuller usage.
