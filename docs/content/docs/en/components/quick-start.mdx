# Quick Start

> **Deprecated as an internal component (2026-09)**: `adp-chat-component` now serves only the platform admin debugging page `/admin/adp-chat` and is no longer distributed or embedded externally. The UMD `<script>`, `window` global-mount, and `mount()` dynamic-mount integrations have been removed. For actual usage, `client/packages/app/src/pages/AdminAdpChat.vue` is the source of truth.

`adp-chat-component` is consumed only by `client/packages/app` via a workspace dependency inside this monorepo; there is no install, publish, or copy-into-external-project step.

## Import

The `package.json` of `client/packages/app` already declares the workspace dependency:

```json
{
  "dependencies": {
    "adp-chat-component": "workspace:*"
  }
}
```

The component library must be built (`dist/es/`) before the app can reference it:

```bash
cd client/packages/adp-chat-component
npm run build
```

## Basic Usage

Import `ADPChat` and its stylesheet, and pass `api-config`. `ADPChat` uses it to automatically load the application list, conversation list, conversation detail, and user info:

```vue
<template>
  <ADPChat :api-config="apiConfig" />
</template>

<script setup lang="ts">
import { ADPChat, type ApiConfig } from 'adp-chat-component'
import 'adp-chat-component/dist/es/adp-chat-component.css'

const apiConfig: ApiConfig = {
  baseURL: '/api',
  // apiDetailConfig can override individual endpoint paths; defaults to defaultApiDetailConfig
}
</script>
```

The debug page also injects platform session-expiry handling through the service-layer interceptor:

```ts
import { setResponseInterceptor } from 'adp-chat-component'

setResponseInterceptor(undefined, (error) => {
  // e.g. catch 401 and redirect to login
  return Promise.reject(error)
})
```

See [ADPChat Component](/docs/en/components/chat-layout) for the full props and events reference.
