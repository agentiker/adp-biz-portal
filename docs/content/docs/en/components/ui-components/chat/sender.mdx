# ChatSender

Message input and send component, built on a native `textarea`. Enter sends, Shift+Enter inserts a newline, Ctrl/⌘+Enter inserts a newline, and Enter during IME composition does not send; a stop button is shown while streaming.

## Usage in Vue

```vue
<template>
  <ChatSender
    :is-stream-load="isLoading"
    @send="handleSend"
    @stop="handleStop"
  />
</template>
```
