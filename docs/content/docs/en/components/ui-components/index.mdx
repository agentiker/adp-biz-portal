# UI Components

> **Internal reference**: `adp-chat-component` has been narrowed to an internal component that only powers the platform admin debug page `/admin/adp-chat`, and the package entry exports only `ADPChat`. The components below are the internal building blocks of `ADPChat`. This section is an internal implementation reference; they are no longer offered as independently importable public SDK components.

This section lists, by category, the UI components used inside `ADPChat`, so their Props/Events/Slots/Methods can be looked up when maintaining the debug page.

## Component Categories

### Layout Components
Basic layout components for building the chat interface structure.
- **MainLayout** - Main content area layout

### Chat Components
Core chat functionality components.
- **Chat** - Main chat message list container
- **ChatItem** - Individual chat message item
- **Sender** - Message input and send component
- **AppType** - Application type selector
- **BackToBottom** - Back-to-bottom button

### Basic Components
Supporting UI components for common functionality.
- **CustomizedIcon** - Custom icon component
- **AIWarning** - AI disclaimer warning

### Common Components
Utility components for various purposes.
- **OptionCard** - Option selection card
- **MdContent** - Markdown content renderer

## Usage Demo

The package entry exports only `ADPChat`; the debug page routes all chat capability through it, and the internal components above are composed by `ADPChat` without being imported separately.

```vue
<template>
  <ADPChat :api-config="apiConfig" />
</template>

<script setup lang="ts">
import { ADPChat, type ApiConfig } from 'adp-chat-component'
import 'adp-chat-component/dist/es/adp-chat-component.css'

const apiConfig: ApiConfig = { baseURL: '/api' }
</script>
```
